# search-to-pdf
Bing搜索 → 网页抓取 → PDF生成 → 邮件发送

这是一个 **n8n 自动化工作流**，能够：
1. 在 **Bing 搜索引擎**中搜索指定关键词
2. 自动**爬取搜索结果中的网页内容**
3. 将内容**转换为 PDF 文件**
4. 通过邮件**发送 PDF 到指定邮箱**

适合用于**资讯监控、竞品调研、学术资料收集**等场景。

---

## ✨ 功能特点

- 🔍 **智能搜索**：支持自定义搜索关键词和过滤规则
- 📄 **自动抓取**：遍历搜索结果页面，提取正文内容
- 📑 **PDF生成**：将网页内容格式化为美观的 PDF
- 📧 **邮件发送**：自动将 PDF 发送到指定邮箱
- ⏱️ **定时运行**：可配合 Schedule Trigger 实现定期监控

**工作流中是手动触发，可以自行更改**

---

## 📋 前置要求

- 已部署的 [n8n](https://n8n.io/) 实例
- 支持 SMTP 的邮箱服务（用于发送邮件）
- 稳定的网络环境（用于访问 Bing 和目标网站）
- 为了让 "Make PDF" 节点（工作流内部的一个节点）正常工作，你需要一个正在运行的 Gotenberg 服务。它负责将 HTML 内容转换为 PDF 文件。

如果你在本地运行 n8n（ `docker` 部署），可以直接在终端执行以下命令。这会在后台启动一个 Gotenberg 容器，并将容器的 3000 端口映射到你电脑的 3000 端口。

```bash
docker run -d --name gotenberg -p 3000:3000 gotenberg/gotenberg:8
```

## 🚀 快速开始

### 1. 导入工作流

1. 下载本仓库的 `json` 文件
2. 在 n8n 中点击右上角 **Import from File**
3. 选择下载的 JSON 文件导入

### 2. 配置参数

工作流开头的 **“输入关键词你的邮箱地址”节点**中包含三个关键参数：

| 参数名     | 说明                         | 示例                                  |
| ---------- | ---------------------------- | ------------------------------------- |
| `key_word` | 要搜索的关键词               | `n8n教程`                             |
| `filter`   | 搜索过滤条件（排除指定网站） | `-site:bilibili.com -site:douyin.com` |
| `email`    | 接收 PDF 的邮箱地址          | `your-email@example.com`              |

**👉 请将 `email` 参数替换为你自己的邮箱**

### 3. 配置邮件凭证

1. 在 n8n 左侧菜单点击 **Credentials**
2. 添加 **Email (SMTP)** 凭证
3. 填写你的邮箱服务器信息：
   - 以 QQ 邮箱为例：`smtp.qq.com`，端口 `465`（SSL）
   - 需要开启 SMTP 服务并获取授权码
4. 在工作流的 **Send Email** 节点中，选择这个凭证

### 4. 运行测试

点击下方的 **Execute Workflow** 按钮测试运行。如果一切正常，你很快就会收到包含搜索结果的 PDF 邮件。


### 添加定时运行

1. 添加 **Schedule Trigger** 节点
2. 设置运行频率（如每天上午 8 点）
3. 连接到 Set 节点前面

## ⚠️ 注意事项

### 关于 Cookie 和反爬
- 部分网站需要 Cookie 才能访问，如果遇到访问失败，可以尝试在 HTTP Request 节点中添加 Cookie Header
- 建议控制请求频率，避免对目标网站造成压力

### 隐私保护
本工作流已做脱敏处理，**不包含任何真实的邮箱地址、密码或 API 密钥**。使用前请：

1. 将 `email` 参数改为你自己的邮箱
2. 配置你自己的邮件凭证
3. 如需分享，请用变量替换敏感信息

## 🐛 常见问题

**Q: 收不到邮件？**  
A: 检查 SMTP 配置是否正确，查看 n8n 执行日志是否有错误。

**Q: 有些网站抓取不到内容？**  
A: 可能因为网站需要 JavaScript 渲染或反爬机制。可以考虑添加 User-Agent Header 或 Cookie。
